【图片放这里 · 命名与规范】
========================================

推荐目录（可按需在 js/data.js 中登记引用）：
  assets/images/            首页以外的日常图片（招新二维码等）
  assets/images/honors/     证书、奖杯照片
  assets/images/races/      比赛现场照片
  assets/images/team/       队员 / 指导老师头像
  assets/images/news/       车队动态配图

图片规范（重要）：
  1. 格式：JPG / PNG / WebP 均可；照片请用横图，比例约 16:9；
  2. 大小：单张建议 ≤ 500KB（手机原图太大，网页会变慢；
     可用“画图 / 美图秀秀 / 在线压缩工具”缩到 1600px 宽以内）；
  3. 命名：全部用英文小写与连字符，例如 news-01.jpg、honor-2025.jpg，
     不要用中文或空格命名（否则部分服务器可能打不开）；
  4. 涉及队员、老师、他人照片，发布前请先获得本人同意。

当前站点还没有引用任何真实图片（以占位色块代替）。
替换步骤见《维护手册》Word 文档的第 3 章，或根目录 README.md。
